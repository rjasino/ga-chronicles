# Problem Definition: Game Ako Game of the Year selection

- **Slug**: go-force-goty
- **Created**: 2026-11-20
- **Inputs used**: intake.md; research.md

## Problem Statement

Game Ako has no process for choosing a community Game of the Year, and the owner wants a live selection event as content for the December 2026 awards period. The owner intends to create demand through the event and a results portfolio for next year rather than wait for proof of existing audience demand.

## Affected Users & Stakeholders

- **Users**: Game Ako players — use their existing Game Ako accounts to participate in the live GOTY selection.
- **Stakeholders**: Game master/admin (the user) — curates eligible titles and facilitates the event.
- **Stakeholders**: Game Ako channel audience — watches the streamed event and can review the post-event portfolio.

## Goals

- Establish a repeatable annual process for selecting Game Ako's GOTY from eligible titles, including community nominations outside the official awards field.
- Be ready for the live event before the user-reported December 10, 2026 Game Awards date.
- Let a variable-size player group participate in one live session, with membership fixed when it begins.
- Make the voting outcome and how the finalists were chosen reviewable after the event.
- Build a results portfolio that can be shared at the following year's event.
- Accept that existing audience demand is not a prerequisite; the content is intended to create demand.

## Non-Goals

- Creating or hosting a video game; `Go Force` is an activity for selecting GOTY.
- Automatically choosing or importing eligible games; the admin manually curates the annual list.
- Supporting participants joining after the session has started.
- Requiring a single GOTY winner when the final ballot is tied.
- Supporting asynchronous participation; the intended activity is a shared live session.
- Publishing results before the live show or selection process is complete.
- Requiring an audience-demand study before building the content feature.

## Success Metrics

- **Deadline readiness**: Go Force is ready for the planned live session before December 10, 2026 (date based on user-provided context; official schedule not independently verified).
- **Completed-session outcome rate**: share of completed sessions that produce at least one named GOTY winner (target: 100%; baseline: no existing process).
- **Required-vote completion rate**: share of expected player vote opportunities submitted during the session (target: at least 80%; baseline: unknown).
- **Post-session results availability**: share of completed sessions with a separate results page available after the event (target: 100%; baseline: no existing process).

## Cost of Inaction

If the feature is not ready for the stated event date, Game Ako misses this planned live-content opportunity. Without the event and post-session results page, the community will not have the GOTY portfolio the owner wants to share at next year's awards period.
